Your Mac — the only thing not already in the cloud

Two Node/bash processes, started as macOS Login Items. This is the entire reason a Mac has to stay on for the pipeline to run at all.

local-agent

5 concurrent poll loops: matching, SMS photo, voice transcription, contact intent, note extraction

watcher

Claude Code CLI

claude -p, sandboxed per skill (skill-profiles.mjs): --strict-mcp-config + a computed --disallowedTools deny list, so a hostile business card can’t reach Gmail, Drive, Supabase admin, or a write-capable Zoho connector.

research-contact match-contact process-cards locate-cards attribute-voice-memo classify-contact-intent extract-note-contacts

process-cards / locate-cards also shell out to macOS’s sips to crop images — the reason this pipeline can’t just move to a Linux server as-is. Voice transcription itself skips the CLI entirely: local-agent calls a local Whisper CLI directly, not a skill.

Every skill prints one JSON object; local-agent validates it (Zod) before writing anything — a failed validation leaves the row pending for a human, never a partial write. Only match-contact ever reaches Zoho, and only through a read-only connector.
